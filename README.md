# Neurito

Cada versión tiene su propia documentación:

| Versión | Tema | Documentación | Ejecutar |
|---|---|---|---|
| 1.0 | Comer, dormir y jugar | [README 1.0](README_1.0.md) | `uv run main.py` |
| 2.0 | Saltar obstáculos | [README 2.0](README_2.0.md) | `uv run saltar.py` |
| 3.0 | Buscar comida en un laberinto | [README 3.0](README_3.0.md) | `uv run laberinto.py` |

Antes de ejecutar una versión, instala las dependencias con `uv sync`.
